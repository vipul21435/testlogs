# testlogs

Turn any test runner's output into per-test results, and diff two runs.

Status: first version. Parsers for pytest (`-v`, `-rA`), JUnit XML and TAP are in;
the other runners in the plan (jest, vitest, mocha, node:test, go test, cargo test)
are not implemented yet.

## Install

```
pip install git+https://github.com/vipul21435/testlogs
```
